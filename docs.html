Lithos Terrain documentation

Version 0.50.0 · for Blender 4.5 LTS and newer

Lithos Terrain is a procedural terrain engine with its own node editor. You build a terrain from nodes (shapes, noise, erosion, snow, colour), Lithos Terrain computes it and writes it to a mesh in your scene, with colour, masks and surface maps ready to render or export.

Requirements

  • Blender 4.5 LTS or newer (tested on 4.5, 5.1, 5.2 and 5.3).
  • No other software or Python packages: the engine is written in Python and NumPy, which ship with Blender.
  • A GPU is optional. Without one everything runs on the CPU; with one, the simulations (erosion, water, snow and others) run many times faster.
  • About 215 MB of disk space for the add-on and its bundled vegetation models and ground textures.

Installation

  1. Download lithos_terrain-0.50.0.zip from your Superhive downloads. Do not unzip it.
  2. In Blender open Edit › Preferences › Get Extensions.
  3. Open the drop-down menu at the top right and choose Install from Disk…, then pick the ZIP file. You can also drag the ZIP file into the Blender window.
  4. Make sure Lithos Terrain is enabled in the list.
  5. In the 3D Viewport press N to open the sidebar and click the Lithos Terrain tab.

Updating: install the new ZIP the same way; it replaces the old version. Restart Blender afterwards. Uninstalling: Preferences › Get Extensions › Lithos Terrain › drop-down › Uninstall.

Quick start

  1. In the Lithos Terrain sidebar tab click New Terrain Project and choose Quick Landscape. A terrain object is created and its preview builds automatically.
  2. Click Open Node Editor. The graph is a single Landscape node connected to Terrain Output.
  3. Select the Landscape node and change Landform, Climate, Age or Snow Line in the node or in the node editor sidebar (Lithos Terrain › Active Node). The preview rebuilds after every change.
  4. Click Build Final for the full-resolution terrain.
  5. Open Sky and Haze and click Set Up Sky and Haze for a sun, sky and aerial haze scaled to the terrain.
  6. Optional: Scatter Layers › Add Biome places trees, shrubs, grass and rocks - or start from a Forests preset, which brings its forest.
  7. Render with Cycles (F12).

Prefer a finished look straight away? Use Preset Library: pick a family, pick a terrain, click Create Terrain from Preset.

The interface

3D Viewport sidebar (N › Lithos Terrain)

  • Lithos Terrain (main panel): the active terrain tree, New Terrain Project (starter templates), Open Node Editor, Save Graph… / Load Graph… and Learn the Nodes: Tutorial.
  • Preset Library: 174 terrains in 25 families with thumbnails. Create Terrain from Preset makes a new project from the chosen preset, with its world size and height.
  • Build: build mode, resolutions, surface maps, mesh settings, Build Preview, Build Final and Export Maps… (see Building).
  • Terrain: the world Size (metres across) and Height (metres from the lowest to the highest point), and the target object.
  • Paint: brush radius and strength for Paint Mask nodes.
  • Outputs: the attributes written to the mesh (colour and masks) for use in your own materials.
  • Material: the automatic terrain material, or your own material.
  • Rocks: scattered boulders and stones on steep, rocky ground.
  • Model Library and Scatter Layers: scatter the bundled models, your own objects or collections, or a whole biome with Add Biome. Each layer has density, size (scale, or real height in metres), spacing, slope and height limits and follows the terrain's masks; trees show in the viewport as light proxies.
  • Ground Textures: close-up ground textures blended by the terrain's cover.
  • Sky and Haze: sun elevation and direction, haze, and Set Up Sky and Haze. Haze starts low (0.05, clear air): shaded slopes take the sky's light first and pale quickly, so raise it only for hazy days and far views.
  • Cache: memory used by cached node results and Clear Cache.

Node editor

Open it with Open Node Editor, or switch any area to the Lithos Terrain editor type.

  • Add nodes with Shift+A. Nodes are grouped into Primitives, Terrain, Modify, Surface, Simulate, Derive, Colorize, Utility and Output.
  • Connect sockets by dragging. Socket colours show the data type: terrain (height), mask (0 to 1) and colour.
  • Every graph ends in Terrain Output. Its Terrain input is the height written to the mesh; its optional Color input is the mesh colour. Without a colour, a default altitude and slope colouring is used.
  • Mask Output nodes write extra masks to the mesh and to exported maps.
  • Node previews: each node shows a thumbnail of its result after a build.
  • Preview This Node (node editor sidebar › Active Node) shows any node's result on the terrain itself: a terrain as the mesh, a mask or a colour painted over it. Click again to return to the output.
  • Node groups: select nodes and use Make Group; Edit enters a group, Ungroup dissolves it.
  • Portals: Portal Send / Portal Receive pass a result across a large graph without long links.
  • The node editor sidebar (N › Lithos Terrain) repeats the Build panel and shows the Active Node with all of its settings, including those hidden on the node.

Building

  • Build Mode › Auto rebuilds the preview a moment after every change. Manual waits for Build Preview or Build Final.
  • Preview Resolution (128 to 512) is for fast iteration. Final Resolution (up to 4096) is for the finished terrain.
  • Builds run in the background: Blender stays responsive, the status line shows the progress and Cancel stops a build.
  • Only the nodes whose inputs or settings changed are computed again; everything else comes from the cache.
  • Surface Maps add colour, normal, roughness and occlusion detail beyond the mesh resolution (Map Resolution up to 8192, Detail, Color Detail, Detail Size, Close-Up Detail, Rock Style).
  • Adaptive Displacement (Cycles) displaces the render mesh to the pixel; Base Mesh and Dicing set its density. Without it, Render Mesh sets a fixed render resolution. Viewport Mesh keeps the viewport light.
  • The terrain is a normal mesh object: you can move, scale, add modifiers or apply it.

Seeds: nodes with randomness have a Seed. The Global Seed (Terrain panel) offsets every seed at once; the button next to it picks a new one.

Surroundings (new in 0.30)

A terrain is a square: a camera that looks across it sees the ground end and empty sky behind it. Surroundings (Build panel) carries the terrain on to the horizon.

  • Turn on Surroundings and click Build Final. An object called ‹terrain› Surroundings appears around the terrain, parented to it.
  • It is made of square rings. Each ring is three times wider and three times coarser than the one inside it. Reach sets the number of rings: 1 ring goes one terrain width past every edge, 2 rings four widths, 3 rings thirteen widths (into the haze of the horizon), 4 rings forty widths (for clear air).
  • The rings are quilted from the terrain itself: pieces of its own landforms at the same size, turned in many directions and joined along hidden seams. They continue the terrain without repeating the tile, and meet its border vertex for vertex.
  • Every ring gets a copy of the terrain material with its own colour, surface maps and cover, so colours, rock style, ground textures and haze go on past the edges. Changing those settings updates the rings without a new build.
  • Ring Detail (256, 512, 1024) is the number of samples per terrain width in the first ring. 512 suits most shots. 1024 is sharper next to the terrain, worth it for a small terrain (a few hundred metres) seen from close by, and needs about 0.8 GB of images per ring.
  • Ring Seed gives another arrangement of the pieces. If a ring mountain stands in front of your camera, or the land right behind the terrain does not suit the shot, try another seed: a new seed rebuilds only the rings.
  • The rings are coarser than the terrain: they are made for the distance. Keep the camera over the terrain, or high above the rings, so that the nearest ground is the terrain itself.
  • The rings are made by Build Final only. A Preview build hides them, because they belong to the last Final build; the next Build Final brings them back.
  • The haze volume and the Lithos camera reach as far as the rings. With your own camera, raise its Clip End so it sees as far as the rings go.

Presets and templates

New Terrain Project offers nine starter graphs: Quick Landscape, Alpine Erosion, Snowy Range, Glacial Valleys, Canyonlands, Volcanic Island, River Valley, Dune Sea and Basic.

The Preset Library has 174 terrains in 25 families: Forests, Nature, Mountain, Glacial, River Valleys, Karst, Faults & Rifts, Coasts & Islands, Deserts, Cliffs, Canyon, Ridge, Stratify, Sandstone, Rock, Rockscape, Crater, Volcano, Water, Cellular, Complex, Fold, Gabor, Drift and Pockmarks. Every preset opens as a normal node graph: change anything, remove nodes or add your own.

The Landscape node (new in 0.29)

One node that builds a complete natural terrain: shape, erosion, rock, snow, water, vegetation and colour.

  • Landform: Mountain Range, Alpine Massif, Highland Valley, Rolling Hills, Canyon, Volcano, and since 0.31 Caldera, Coastline, Island and Dune Sea. Coastline and Island meet the sea with cliffs, sea stacks and sandy coves (in the Alpine and Cold climates the glaciers' troughs become fjords); Dune Sea is a sand sea with slip faces. Since 0.40: River Plain (a meandering river on its floodplain, braided in the Alpine and Cold climates), Tower Karst and Rift Valley.
  • Climate: Alpine, Temperate, Arid, Cold. Sets the colours, vegetation, snow and how much water the land holds.
  • Age: young, sharp relief (0) to old, worn relief (1).
  • Scale: the size of the landforms relative to the terrain.
  • Snow Line (Alpine and Cold): where the snow starts.
  • Water: None, Rivers, or Rivers and Lakes.
  • Vegetation and Detail: how much vegetation and how much fine surface detail.
  • Outputs: Terrain, Color and six masks (Rock, Snow, Water, Vegetation, Flow, Sediment). Connect Terrain and Color to Terrain Output for a finished terrain; use the masks for scattering, materials or further nodes.

The Landscape node runs a full graph inside, so its first build takes longer than a single simple node; changing a setting only recomputes the steps after it.

A good order for a natural mountain: Mountain → Stream Erosion → Erosion → Snow → Terrain Colors → Terrain Output. Stream Erosion shapes the valleys, Erosion adds the detail and sediment, Snow and colour finish it.

Rock structure (new in 0.29): add a Rock Layers node fed by your terrain and connect its Hardness and Strata outputs to the Hardness and Strata inputs of Stream Erosion or Thermal Erosion. Hard beds then stand as cliffs up to the Cliff Angle and soft beds fail into talus, so canyon walls come out stepped. Rock Variation on Stream Erosion breaks up evenly spaced gullies on steep faces. The Layers output gives one tone per bed for colour bands.

Your own data

  • Object Height turns any mesh object into a terrain (seen from above). Erode it like any other terrain.
  • Heightmap Image reads a height map image (PNG, EXR, TIFF and any format Blender reads).
  • Paint Mask lets you paint a mask directly on the terrain in the viewport (Paint panel for brush radius and strength). Use it to limit erosion, place snow or blend terrains by hand.

Export

Build › Export Maps… writes the terrain's maps for other applications and game engines.

  • Formats: PNG 16-bit, OpenEXR (float), RAW 16-bit (.r16), RAW 32-bit float (.r32).
  • Resolution: 64 to 8193 samples per side. Unity terrains use 513, 1025, 2049 or 4097; Unreal landscapes 505, 1009, 2017, 4033 or 8129.
  • Tiles: 1 × 1, 2 × 2, 4 × 4 or 8 × 8 files per map.
  • Maps: height, colour (sRGB), every mask from Mask Output nodes, and normal (OpenGL or DirectX), roughness and occlusion.
  • A JSON sidecar records the world size, the height range and the encoding of every file, so the terrain can be rebuilt at the right scale.

Save Graph… / Load Graph… store a node graph as a file to reuse it in another project or share it.

Preferences

Edit › Preferences › Add-ons › Lithos Terrain:

  • Use GPU: run the simulations on the GPU when Blender has a GPU context (normal windowed Blender). Command-line renders in background mode use the CPU.
  • Cache Budget (MB): memory for cached node results (default 4096). Larger budgets keep more of a big graph cached.
  • Worker Threads: CPU threads for a build; 0 picks automatically.

Performance tips

  • Work in Auto mode at Preview 256, and build Final when you are happy.
  • Results are cached per node: editing a node after a heavy simulation keeps the simulation cached, editing a node before it runs it again. Settle the early nodes first.
  • Final 4096 with 4096 surface maps needs several GB of memory; use 2048 on machines with 16 GB or less.
  • Mute a node (M) to skip it while you test.
  • Clear Cache (Cache panel) frees the memory of cached results.

Troubleshooting

  • No Lithos Terrain tab: check that the extension is enabled in Preferences › Get Extensions and that the 3D Viewport sidebar (N) is open.
  • "Graph changed – press Build": the build mode is Manual; click Build Preview or Build Final.
  • A node shows an error: a required input is not connected, or the graph contains a loop. The node and the build status line name the problem.
  • The terrain looks blocky in the render: build Final, enable Surface Maps, and use Adaptive Displacement in Cycles (or raise Render Mesh).
  • Builds are slow: lower the Final or Map Resolution, enable Use GPU in the preferences, and avoid re-running heavy simulations by editing the nodes after them.
  • Out of memory: lower the Final Resolution and the Cache Budget, or clear the cache.
  • The ground ends behind the terrain: turn on Surroundings and click Build Final. If the far rings are cut off, raise the camera's Clip End.

Support

Questions, bug reports and suggestions: use the Ask a Question / support button on the Superhive product page. Please include your Blender version, your operating system and, when you can, the graph (Save Graph…) that shows the problem.

Forests (new in 0.50)

Scatter layers plant forests the way they grow:

  • Size › Real Height: each tree is given a height in metres between Height Min and Max (spread evenly;

none is ever smaller than Height Min). Every variant of the model is measured and brought to that height, whatever its own size or scale. The biomes and the Model Library start each tree at its real range: firs 15 to 32 m, pines 14 to 28 m, saplings 1 to 2.5 m. Scale keeps the old behaviour: a random scale of the model's own size.

  • Density and Spacing: Density is the number per 100 m² where the ground suits fully (4 = 400 a hectare).

Spacing keeps trees at least that share of their crown width apart (Poisson distribution): at 0.5 crowns barely touch, like a natural stand, and the spacing caps how dense a layer gets. The layer shows its count, trees per hectare and mean height.

  • Smaller at Edges: trees grow smaller where their ground fades out - at the edges of woods and clearings and

toward the tree line (Ground Max, as a share of the terrain height) - by at most 30 % and never below Height Min (or Scale Min).

  • On the vegetation: when the terrain has a vegetation cover (a Vegetation or Landscape node), tree layers grow

on it (Cover › Vegetation), so the ground under a forest has the vegetation's dark colour and bare soil and scree stay open. Dry open woodland (Mediterranean, Dry Scrubland) and terrains without vegetation use Open Ground.

  • Viewport › Proxies: each tree shows in the viewport as a light shape of its own model (about 120 triangles,

coloured like its leaves and bark), so a forest of hundreds of thousands of trees shows in full at its real size and density. Renders use the full models with their levels of detail.

  • Your own trees: make a collection of your tree objects active and press + in Scatter Layers. Each root object

with its children is one variant (a trunk with its leaves stays whole) and keeps its rotation and scale (an FBX import at 0.01 scale or turned 90 degrees stands as you see it). Models at least 2.5 m tall get the tree settings: real heights around their own, spacing and proxies.

  • Biomes: Conifer Forest, Fir Forest, Pine Forest, Broadleaf Forest, Broadleaf Woodland, Mountain Forest (broadleaf

trees in the valleys, pines and firs above, stunted pines at the tree line, meadow over it), Mediterranean Woodland, Parkland, Dry Scrubland and Alpine Meadow.

  • Forests presets: Fir Valley, Mountain Forest, Pine Hills, Forest River, Olive Hills and Parkland come with their

forest: Create Terrain from Preset adds the biome's layers, and the trees grow with the first Final build.

A large forest is light to render: every tree of a kind shares one mesh, so memory grows with the number of models, not with the number of trees.

Rivers, karst, lava, faults and wind (new in 0.40)

  • River Plain lays a river across any terrain. It finds the cheapest course along Direction (with **Follow

Valleys it keeps to the low ground), levels a floodplain along it and lets the river fall steadily downstream; where the ground rises in its way it cuts a gorge. Meandering: one channel winding in bends (Sinuosity, Bend Length), deeper on the outside of each bend with a sand point bar on the inside, Oxbow Lakes left by cut-off bends and the wet swales of Old Channels. Braided**: many shallow channels splitting and joining over a wide gravel bed. Outputs: the terrain (with the water surface), Water, Floodplain, Sand and Wet Ground (for vegetation).

  • Karst dissolves limestone: Sinkholes in a plateau, Cone Karst (steep cones around closed hollows) or

Tower Karst (steep-walled towers on a flat plain). Outputs: Rock, Hollows and Plain masks.

  • Lava Flow sends tongues of lava from vents down the terrain: they follow the valleys, branch, widen and end in

lobes, with pressure ridges and a rough surface. Old Flows sets the share of weathered flows; the Fresh Lava mask is the young, black lava.

  • Fault breaks the ground along a line: a Scarp, a Rift Valley, a Raised Block or Steps, with

Throw, Scarp Angle and Erosion (facets and gullies on the scarp).

  • Wind Erosion wears the ground with wind-blown sand into Yardangs (ridges like upturned hulls) between scoured

corridors, streamlines the forms along the wind and leaves sand in the lee.

  • Curve Path lays a Blender curve (or an edge mesh) into the terrain as a Road (cut and fill to an even grade,

with shoulders), a River (a channel that only flows downhill, with water), a Ridge or a Valley. Press + on the node for a new curve across the terrain, or pick your own; move its points in the viewport and the path is read again on every build. Height From Curve uses the curve's own heights.

New preset families: River Valleys, Karst and Faults & Rifts, plus Lava Field and Fresh Lava Flow (Volcano) and Yardang Field (Deserts). The Landscape node has three new landforms: River Plain (braided in the Alpine and Cold climates), Tower Karst and Rift Valley.

Coasts (new in 0.31)

The Coast node turns any terrain into a coastline at its Sea Level. The waves cut the shore back (Retreat), most on exposed headlands and in soft rock: over that distance the ground becomes a shore platform just under the water, and behind it the land ends in a cliff as steep as the rock is hard (Hardness, or connect Rock Layers' Hardness output). Sea Stacks leaves hard remnants standing on the platform, Beaches fills the sheltered bays with sand, and the drowned valleys silt up into a smooth sea floor. Outputs: the terrain and the Sea, Beach, Cliff and Platform masks. Add a Water node (Sea, Flat Water Surface on) after it for the sea surface, and feed Beach into Terrain Colors' Sediment for the sand. The Coasts & Islands presets show complete coast graphs.

floor, with Sea, Beach, Cliff and Platform masks.

  • New preset families: Coasts & Islands (Rocky Coast, White Cliffs, Rugged Island, Archipelago, Fjord, Black Sand

Coast, Sandy Bays), Deserts (Dune Sea, Pale Dunes, Mesas and Dunes, Desert Range, Painted Hills, Flatirons) and Cliffs (Layered Cliff, Granite Wall, Landslide Scar, Craggy Slope); four new volcanoes (Extinct Volcano, Collapsed Caldera, Maar Lakes, Snow Cone). 156 presets in 21 families.

  • The Landscape node has four new landforms: Caldera, Coastline, Island and Dune Sea.
  • Coast presets colour the shallow sea lighter over the shore platform and the sand.

0.30.1

  • Runs on Blender 4.5 LTS and newer (tested on 4.5, 5.1, 5.2 and 5.3); before, 5.2 or newer.
  • On Blender 4.5, Adaptive Displacement switches Cycles to the Experimental feature set, the only one with adaptive subdivision in 4.5.

0.30.0

  • New Surroundings: Build Final carries the terrain on to the horizon with rings quilted from its own landforms (1 to 4 rings, one to forty terrain widths past every edge), with the terrain's colours, surface maps, rock style, ground textures and haze.
  • The haze volume and the Lithos camera reach as far as the surroundings.
  • Close-up rock detail: no more regular grid of fine lines on rock faces; beds of uneven thickness, faint and wandering ledges, sparse cracks; a less brick-like Sandstone style.
  • Fixed: black slits and flakes on rock faces in Cycles renders with Adaptive Displacement. Cycles now shades the displaced terrain with the displaced surface's own normal; EEVEE and the viewport keep the normal map.

0.29.0

  • New Landscape node: a complete natural terrain from one node (6 landforms, 4 climates, age, scale, snow line, water, vegetation, detail; terrain, colour and six masks). New Quick Landscape template.
  • New Rock Layers node: hard and soft beds with dip, folds and caprock. Stream Erosion and Thermal Erosion use its Hardness and Strata for stepped cliffs and talus; new Cliff Angle, Rock Variation and Scree Angle settings.
  • Erosion: no worm-like ridges, much less sediment sheeting, crisp V-shaped banks; mass stays exact. New defaults: Gullies 0.03, Sediment Removal 0.2.
  • Performance: CPU Final builds up to 5× faster with identical results; one shared thread pool.
  • The default colouring follows the Worker Threads preference.
